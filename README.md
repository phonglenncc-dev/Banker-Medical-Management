## 📋 Giới thiệu đề tài
Đồ án xây dựng chương trình mô phỏng thuật toán **Banker** (phòng tránh bế tắc - Deadlock avoidance) trong hệ điều hành[cite: 10], được áp dụng vào bài toán thực tế tại bệnh viện: quản lý và phân bổ an toàn các trang thiết bị y tế khan hiếm dùng chung giữa các khoa/phòng (như Máy thở, Máy theo dõi sinh hiệu, Bơm tiêm điện, Xe vận chuyển).
